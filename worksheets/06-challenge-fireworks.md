# Challenge - Fireworks

## The challenge 
Create a new script called `Fireworks.py` that uses Turtle to create a fireworks display!

Each firework could:
- be a random size
- in a random location
- in a random colour
- disappear after a short amount of time

Hint: you can draw fireworks as lines coming out from a central point.

## Extension

Using what you learnt on the Events challenge, could you make the fireworks be drawn where the user clicks?
